# CampusConnect – Campus Event Finder

## Project Overview
CampusConnect is a fictional campus event finder platform that helps students discover upcoming events and activities in their school.

## Features
- View upcoming campus events.
- Discover school activities.
- Check event dates and locations.
- Stay updated with campus announcements.

## How to Use
1. Open CampusConnect.
2. Browse upcoming events.
3. Select an event.
4. Check its date, time, and location.
5. Attend your chosen event!
